# gta6-meme-x-01

Entry for make.fun's GTA 6 meme bounty (gta6-meme-x-01).

The entry is this X post by @mangkarones, a hospital scene meme drawn from code:
the make.fun ghost as a patient in a Leonida General Hospital bed, PlayStation
controller in hand, certified unfit for work for GTA VI launch week, with the
treatment paid by his AI agent on make.fun.

Post: https://x.com/mangkarones/status/2124859641440215387

`POST.json` holds the post's address. Running `main.ts` (Node 22) copies
`POST.json` into the output directory (`MAKEFUN_OUTPUT_DIR`, default `/output`),
reading the source from `MAKEFUN_BOT_DIR` (default: current directory).

The meme image is `meme.png`.
